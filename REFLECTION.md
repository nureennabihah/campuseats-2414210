# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?
   I learned that plain DOM code requires us to change the UI step by step, while React describe what we want the UI to look like.

2. Why must a component name start with a capital letter?
   So that React can recognize them as components.

3. What does a fragment <>...</> do, and why not just use a <div>?
   Fragment is used to group elements together without adding an extra <div>.

4. Name one benefit of splitting the UI into small components.
   it makes the code easier to understand and maintain because each component handles a specific part of the UI.
